# coffee
A subsection of my website dedicated to me love for coffee!

## What lives here

| Path | What it is |
|---|---|
| `/` | The coffee home page, `index.html` |
| `/sip/` | Sip Log, a shared coffee timer for two people, source in `src/sip/` |

Built with Vite and React. `npm install`, then `npm run dev` to work locally and `npm run build` to produce `dist/`.
